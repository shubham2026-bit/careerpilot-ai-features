================================================================================
                    STEP-BY-STEP SETUP INSTRUCTIONS
================================================================================

1. CREATE SUPABASE PROJECT
   ├─ Go to https://supabase.com
   ├─ Click "New Project"
   ├─ Fill in project name, password, region
   ├─ Wait for database to initialize (2-3 minutes)
   ├─ Go to Settings → API
   ├─ Copy:
   │  ├─ Project URL → NEXT_PUBLIC_SUPABASE_URL
   │  ├─ anon public key → NEXT_PUBLIC_SUPABASE_ANON_KEY
   │  └─ service_role key → SUPABASE_SERVICE_ROLE_KEY
   └─ (Save these 3 keys)

2. GENERATE AUTHENTICATION SECRETS
   ├─ Open Terminal and run:
   │  ├─ openssl rand -base64 32  (copy output → BETTER_AUTH_SECRET)
   │  └─ openssl rand -base64 32  (copy output → CRON_SECRET)
   └─ (You now have 2 secrets)

3. GET OPENAI API KEY
   ├─ Go to https://platform.openai.com/account/api-keys
   ├─ Click "Create new secret key"
   ├─ Copy the key → OPENAI_API_KEY
   └─ (Save this key)

4. GET BREVO EMAIL KEY
   ├─ Go to https://brevo.com
   ├─ Sign up or login
   ├─ Go to SMTP & API
   ├─ Copy API Key → BREVO_API_KEY
   ├─ Set EMAIL_FROM to your domain (e.g., noreply@yourdomain.com)
   └─ (You now have email setup)

5. GET GITHUB OAUTH (OPTIONAL)
   ├─ Go to https://github.com/settings/developers
   ├─ Click "New OAuth App"
   ├─ Fill in application name
   ├─ Authorization callback URL: https://yourdomain.com/api/auth/github/callback
   ├─ Copy:
   │  ├─ Client ID → GITHUB_OAUTH_CLIENT_ID
   │  └─ Client Secret → GITHUB_OAUTH_CLIENT_SECRET
   └─ (Optional - skip if not needed)

6. GET LINKEDIN OAUTH (OPTIONAL)
   ├─ Go to https://linkedin.com/developers/apps
   ├─ Create new app
   ├─ Authorized redirect URLs: https://yourdomain.com/api/auth/linkedin/callback
   ├─ Copy:
   │  ├─ Client ID → LINKEDIN_OAUTH_CLIENT_ID
   │  └─ Client Secret → LINKEDIN_OAUTH_CLIENT_SECRET
   └─ (Optional - skip if not needed)

7. ADD TO VERCEL
   ├─ Go to https://vercel.com/dashboard
   ├─ Select your CareerPilot project
   ├─ Settings → Environment Variables
   ├─ Paste all variables above
   └─ Deploy

================================================================================
                            TROUBLESHOOTING
================================================================================

If something doesn't work:

❌ Database errors → Check NEXT_PUBLIC_SUPABASE_URL and SUPABASE_SERVICE_ROLE_KEY
❌ Login fails → Check BETTER_AUTH_SECRET and BETTER_AUTH_URL
❌ Email not sending → Check BREVO_API_KEY and EMAIL_FROM
❌ AI features fail → Check OPENAI_API_KEY
❌ Cron jobs fail → Check CRON_SECRET
❌ OAuth not working → Check GitHub/LinkedIn Client ID/Secret

To debug in Vercel:
1. Go to Deployments → select latest
2. Check Function Logs
3. Look for error messages
4. Update env vars if needed
5. Redeploy

================================================================================
                            SECURITY NOTES
================================================================================

⚠️  IMPORTANT:
- Never commit .env files to Git
- Never share API keys publicly
- Rotate keys regularly
- Use strong secrets (use openssl to generate)
- Keep Supabase service role key SECRET (only on server)
- Use anon key for CLIENT (NEXT_PUBLIC_ prefix)

⚠️  BEFORE PRODUCTION:
- Test all features with real credentials
- Verify email domain in Brevo
- Set up custom domain in Vercel
- Enable SSL/HTTPS
- Configure backups in Supabase
- Set up monitoring/logging
